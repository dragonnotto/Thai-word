# 👑 เกมเรียนรู้คำราชาศัพท์ไทย (Thai Royal Vocabulary Game)

เว็บแอปเกมการเรียนรู้ **คำราชาศัพท์ของไทย** แบบครบวงจร สร้างด้วย HTML/CSS/JavaScript ล้วน
เปิดเล่นได้ทันทีโดยไม่ต้องติดตั้งอะไร และนำขึ้น GitHub Pages ได้เลย

## ✨ คุณสมบัติ

### 🎮 4 โหมดเกม
| โหมด | รายละเอียด |
|------|-----------|
| 📝 **ควิซปรนัย** | เลือกคำราชาศัพท์ให้ตรงกับคำสามัญ จาก 4 ตัวเลือก |
| 🔗 **จับคู่คำ** | คลิกจับคู่คำสามัญกับคำราชาศัพท์ (ครั้งละ 5 คู่) |
| ✍️ **เติมคำ** | พิมพ์คำราชาศัพท์ลงในช่องว่างของประโยค |
| 🃏 **บัตรคำทบทวน** | พลิกบัตรคำเพื่อทบทวนความหมายและตัวอย่างประโยค |

### 🧩 ฟีเจอร์เสริม
- 🔊 **เสียงประกอบ** ถูก/ผิด ด้วย Web Audio API
- 🗣️ **อ่านออกเสียงไทย** (Text-to-Speech) สำหรับฟังคำราชาศัพท์
- ⭐ **ระบบคะแนน + คอมโบ (streak)** ยิ่งตอบถูกต่อเนื่องยิ่งได้โบนัส
- ⏱️ **จับเวลา** ในแต่ละรอบ
- 🎚️ **เลือกระดับความยาก** (ง่าย / ปานกลาง / ยาก) และจำนวนข้อ
- 💾 **บันทึกสถิติ** ด้วย `localStorage` (คะแนนสูงสุด, ความแม่นยำ, จำนวนครั้งที่เล่น)
- 📱 **รองรับมือถือ** (responsive) ธีมไทยประยุกต์โทนทอง-แดง

### 📚 เนื้อหา
คำราชาศัพท์ครบ **7 หมวด** รวม 126 คำ:
ร่างกายและอวัยวะ · เครือญาติ · คำกริยา · เครื่องใช้ · อาหารและเครื่องเสวย · เครื่องแต่งกาย · คำสำหรับพระสงฆ์

## 🚀 วิธีใช้งาน
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์ในเครื่อง:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

### นำขึ้น GitHub Pages
ไปที่ **Settings → Pages** เลือก branch แล้วเว็บจะพร้อมใช้งานทันที (ไม่ต้อง build)

## 📁 โครงสร้างไฟล์
```
index.html              หน้าหลัก + โครงสร้างหน้าจอทั้งหมด
css/style.css           ธีมและสไตล์ทั้งหมด
js/data.js              ฐานข้อมูลคำราชาศัพท์
js/audio.js             ระบบเสียงและอ่านออกเสียง
js/app.js               ตัวควบคุมหลัก (นำทาง, คะแนน, สถิติ)
js/games/quiz.js        โหมดควิซปรนัย
js/games/matching.js    โหมดจับคู่คำ
js/games/fill.js        โหมดเติมคำ
js/games/flashcard.js   โหมดบัตรคำ
```

## 📝 หมายเหตุเรื่องเนื้อหา
คำราชาศัพท์อ้างอิงตามหลักภาษาไทย เหมาะสำหรับการเรียนรู้และทบทวน
หากต้องการเพิ่ม/แก้ไขคำ สามารถแก้ไขที่ `js/data.js` ได้โดยตรง
